# aero

**aero** — собственная версия [Baseline](https://github.com/svnaxis/obsidian-baseline) для Obsidian с **полными исходниками**, оригинальными стилями и функциями, а также отдельными персональными настройками.

> Неофициальная модификация. Автор оригинальной Baseline: [svnaxis](https://github.com/svnaxis). Оригинальная лицензия MIT сохранена в `LICENSE.txt`, исходное описание — в `UPSTREAM_README.md`.

## Что сохранено

- Все исходные темы оформления и цветовые схемы Baseline;
- варианты рабочих областей и стили элементов, в том числе Cupertino, Material, Fluent и Adwaita;
- оригинальные настройки Style Settings;
- стили редактора, таблиц, Bases, callout, баннеров, карточек, изображений, Dataview и проводника;
- мобильные стили и исходные возможности темы.

Дополнительно есть раздел **Style Settings → Мои настройки**. Отдельно включаются скругления, прозрачные панели и блюр, скрытие фоновых плашек у кнопок, линии проводника, компактные заголовки и выделение выбранных элементов. Все новые опции изначально выключены, чтобы исходный вид не менялся самопроизвольно.

## Установка через BRAT

1. Установи и включи плагин BRAT в Obsidian.
2. В BRAT используй **Add / Grab a beta theme for testing**.
3. Введи URL **своего нового репозитория** (не ссылка на эту рабочую ветку).
4. После загрузки выбери тему **aero** в `Настройки → Оформление → Темы`.

BRAT загружает готовые `theme.css` и `manifest.json` из основной ветки. Для получения обновлений при каждом изменении SCSS используется GitHub Actions, автоматически обновляющий `theme.css`.

## Как сделать независимый репозиторий

Проект пока находится в рабочей ветке `personal-customization` исходного форка `thefawels/obsidian-baseline`. Чтобы завести **отдельный** самостоятельный репозиторий:

1. Перейди на **https://github.com/new/import**.
2. Укажи Source repository URL: `https://github.com/thefawels/obsidian-baseline.git`.
3. Owner: `thefawels`, Name: например, `aero`, видимость: Public (для BRAT это проще).
4. После импорта открой **Settings → Branches → Default branch** нового репозитория и выбери `personal-customization`. При желании переименуй её в `main`.
5. Проверь, что в выбранной основной ветке есть `theme.css`, `manifest.json` и `src/custom/personal.scss`.
6. Если GitHub Actions не активны, включи их в новом репозитории. В разделе **Actions** можно вручную запустить `Build theme.css`.

**Важно:** пока основной веткой остаётся старый `main`, BRAT будет устанавливать оригинал вместо персональной темы.

## Сборка исходников

Нужен Node.js 22+:

```bash
npm install
npm run build
```

Для разработки с непрерывной пересборкой:

```bash
npm run watch
```

- `src/theme.scss` подключает все исходные SCSS и персональный модуль последним;
- `src/custom/personal.scss` содержит новые CSS-правила;
- `src/app/style-settings.scss` содержит оригинальные и новые настройки;
- `theme.css` — готовый файл для BRAT и Obsidian.

Файл `.github/workflows/build-theme.yml` компилирует CSS при каждом изменении исходников в основной ветке и при необходимости фиксирует обновлённый `theme.css`.

## Релизы

Версия задаётся в `manifest.json`. Для публикации новой версии обнови её, зафиксируй изменения и отправь тег в формате `v1.0.0`. Workflow `Publish Baseline Personal` собирает все стили и создаёт GitHub Release с готовыми файлами `theme.css` и `manifest.json`.
